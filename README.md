# Tblochii-genomics-workflows

Public Snakemake workflows for the *Trachinotus blochii* cold-tolerance genomics project.

- `wgs/`: whole-genome resequencing, variant discovery, population structure and GWAS workflow.
- `rnaseq/`: RNA-seq quality control, alignment, expression quantification, differential expression and PCA/correlation workflow.

Each workflow is independent. See the corresponding `README.md` and `config/config.yaml` before running.
