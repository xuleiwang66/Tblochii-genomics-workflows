# Trachinotus blochii genomics workflows

This repository contains two Snakemake workflows used for whole-genome resequencing and RNA-seq data processing and downstream analyses.

## Workflows

* `wgs`: whole-genome resequencing workflow
* `rnaseq`: RNA-seq workflow

## Status

Under development.

Each workflow is independent. See the corresponding `README.md` and `config/config.yaml` before running.
